# Happy Monthsary

A full-screen animated greeting with seven white and purple tulips. Stems grow, leaves unfurl, and petals open in a staggered sequence. Gentle swaying, fireflies, falling petals, and touch-triggered sparkles complete the garden. The only visible text is "Happy Monthsary".

Live: https://reaganjade12.github.io/flower-greeting/

Plain HTML, CSS, JavaScript, and SVG, hosted from the main branch on GitHub Pages. No build step or backend required. Open index.html directly or run python -m http.server 8080. Animation plays automatically, including when Windows motion effects are disabled. The icon in the corner pauses or resumes the entire scene. A continuous spiral of glowing hearts and sparks surrounds the swaying, opening flowers. Google Fonts is optional; a local serif fallback is included.
